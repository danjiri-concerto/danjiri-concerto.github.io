## ローカル開発

```bash
# Python 3
python3 -m http.server 8000
```

→ http://localhost:8000/ でプレビュー

> `fetch()` によるHTMLフラグメント読み込みを使用しているため、直接ファイルを開くのではなくローカルサーバーが必要です。
