About

MINIMUM JOURNEY -BLUR- is an expansion for the space exploration board game MINIMUM JOURNEY.

As exploration of the abyss advances, the exploration ships encounter strange phenomena. Ships reach the very same coordinates, yet the observations each one brings back are completely different.

A different event card is revealed every round, so you decide based not only on the table in front of you, but on what is going to happen this round. Read the unpredictable and stay one step ahead of the other players.

Players 3–6
Play time 20–40 min
Weight BGG 2.2/5.0
Price 2,000 JPY
Released Spring 2026

* This expansion requires the MINIMUM JOURNEY base game.

Cards

Event cards that shake up the table every round, plus a set of new cards unique to BLUR.
